# De vibecodeur à dev senior IA

Formation itsmoha.ia : construire une vraie app avec Claude Code et la méthode BMAD, pour les entrepreneurs non-développeurs.

Ce dépôt contient tout ce qui sert à produire la formation : décisions, plan, scripts des leçons, voix off, visuels, enregistrements et montages.

## Contenu

| Dossier | Rôle |
|---|---|
| `docs/decisions.md` | Toutes les décisions validées (offre, contenu, production) |
| `docs/voix/` | Texte d'enregistrement pour le clone de voix, réglages ElevenLabs |
| `assets/mascotte/` | Avatar 3D de Moha (3 poses + planche) |

À venir : `docs/plan.md` (programme leçon par leçon), `lecons/` (scripts, quiz, défis), `remotion/` (montage), `enregistrements/`.
